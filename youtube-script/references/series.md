# series.md — 시리즈 설계

## 1. 시리즈로 갈 조건

| 시리즈로 | 단편으로 |
|---|---|
| 관통 질문 하나에 **독립된 하위 질문 3개 이상**이 딸려 있다 | 질문이 하나고 답도 하나다 |
| 한 편에 담으면 층 2까지밖에 못 판다 | 18분에 층 4까지 도달한다 |
| 시간·주체·관점이 여러 겹이다 | 단일 사건, 단일 관점 |
| 각 편에 서로 다른 반전이 있다 | 반전이 하나뿐 |

주제가 크다는 이유만으로 시리즈로 만들지 않는다. **각 편이 자기 반전을 가질 수 없으면 시리즈가 아니라 긴 단편**이다.

## 2. 시리즈 축 (하나만 고른다)

| 축 | 분할 방식 | 잘 맞는 주제 | 편수 |
|---|---|---|---|
| **층위축** | 현상 → 구조 → 이해관계 → 전망 | 산업·정책·기술 분석 | 3~4 |
| **연대기축** | 시간 순서. 편마다 국면이 바뀐다 | 사건, 기업사, 전쟁, 몰락과 부활 | 4~6 |
| **인물축** | 편마다 다른 인물의 눈으로 같은 사건 | 갈등, 재판, 협상, 다중 이해관계 | 3~5 |
| **질문축** | 편마다 하나의 질문. 답이 다음 질문을 만든다 | 미스터리, 통설 검증 | 3~5 |
| **사례축** | 편마다 다른 사례, 마지막 편에서 공통 원리 | 방법론, 패턴 분석 | 4~6 |

- **편수는 3~6편.** 3편 미만은 시리즈감이 아니고, 7편 넘으면 완주율이 무너진다.
- 사례축은 편이 서로 독립적이어서 이탈이 쉽다. **관통 질문을 매 편 콜드 오픈에서 다시 세운다.**

## 3. 나쁜 분할 vs 좋은 분할

### 나쁜 분할 — 목차 자르기

```
1편 반도체란 무엇인가 (정의)
2편 반도체 산업의 역사
3편 주요 기업들
4편 앞으로의 전망
```

1편이 교과서다. 아무도 2편까지 안 간다. **정의·역사·현황·전망은 편의 소재가 아니라 한 편 안의 층**이다.

### 좋은 분할 — 편마다 질문·반전·갈고리

```
1편 «공장은 세워졌다, 그런데»
    질문: 준공식 뒤 2년간 무슨 일이 있었나
    반전: 지연 원인은 돈도 인력도 아니었다
    갈고리: 그 병목의 이름은 다음 편에서

2편 «전기가 없다»
    질문: 왜 20년 된 규정이 최신 공장을 멈췄나
    반전: 같은 규정을 받은 옆 주는 14개월 만에 끝냈다
    갈고리: 두 주의 차이를 만든 한 사람
```

각 편은 **1편만 봐도 완결**되고, **다 보면 더 큰 그림**이 생긴다. 이 두 조건을 동시에 만족해야 한다.

## 4. 편별 3요소 (설계 시 반드시 작성)

| 요소 | 조건 |
|---|---|
| **핵심 질문** | 그 편이 답하는 질문 하나. 두 개면 편을 쪼갠다 |
| **반전** | 시청자의 기존 이해를 뒤집는 사실 하나. 근거 필수 |
| **갈고리** | 다음 편으로 넘기는 미해결 질문. 마지막 편은 갈고리 대신 **관통 질문의 최종 답** |

셋 중 하나라도 써지지 않는 편은 독립된 편이 아니다 — 합치거나 축을 바꾼다.

## 5. 관통 루프 (시리즈 대루프)

시리즈 전체를 관통하는 **미해결 질문 하나**를 세우고, 마지막 편에서 회수한다.

- 모든 편의 프레이밍이 이 질문을 향한다. 편마다 답의 조각을 하나씩 준다.
- 관통 질문은 **1편 콜드 오픈에서 명시적으로 던진다.** 시리즈 제목이 그 질문의 축약이면 가장 좋다.
- 편별 루프(편 안에서 열고 닫음)와 관통 루프(마지막 편에서 닫음)를 구분해 장부에 적는다.

## 6. 편간 연결

### 콜드 오픈 회수 (2편 이후)

전편을 안 본 사람도 이해되게 **1~2문장**으로 회수한다. 요약이 아니라 **긴장 복원**이다.

> ✗ "지난 편에서는 애리조나 공장의 지연 원인을 살펴봤습니다."
> ✓ "지난 편 마지막에 남은 질문은 이거였습니다. 전기가 없어서 공장이 멈춘다는 게, 2024년에 가능한 일인가."

회수 문장은 콜드 오픈 **뒤**에 놓는다. 회수로 편을 시작하면 신규 시청자를 잃는다.
**순서: 장면 투척 → 회수 1~2문장 → 이번 편 프레이밍.**

### 엔딩 갈고리

- 예고가 아니라 **질문**으로. "다음 편에서는 ~를 다룹니다" ✗ / "그런데 이 계산에 한 사람이 빠져 있었습니다" ✓
- 갈고리는 다음 편 콜드 오픈과 실제로 이어져야 한다. 던지고 안 받으면 신뢰가 깨진다.

### 시그니처 반복

시리즈에 **반복 장치 1~2개**를 정해 매 편 같은 자리에 쓴다. 반복이 시리즈를 시리즈로 만든다.

- 오프닝 시그니처 문구 (콜드 오픈 직후 고정 한 문장)
- 클로징 시그니처 문구
- 편마다 같은 형식으로 등장하는 장치 (예: 매 편 한 사람의 증언으로 시작, 매 편 숫자 하나로 끝)

**구조는 반복하고 소재로 변주한다.** 구조가 매 편 바뀌면 시청자가 매번 적응해야 한다.

## 7. 집필 순서

1. **1편을 먼저 완성해 톤 앵커로 확정한다.** 그다음 2편 이후를 서브에이전트에 병렬 위임한다 (`delegation.md`). 앵커 없이 전체를 동시에 쓰면 문체·호칭·용어 표기가 편마다 갈린다.
2. **모든 편의 3요소(질문·반전·갈고리)는 1편 집필 전에 확정**한다. 반전을 미리 배분하지 않으면 앞 편에서 카드를 다 써버린다.
3. **갈고리는 문장 수준으로 확정해 바이블에 적는다.** 병렬 집필에서 N편 담당은 N-1편 결과물을 볼 수 없다. 넘길 문장과 받을 문장이 바이블에 있어야 편간 연결이 어긋나지 않는다.
4. 마지막 편은 관통 질문에 답한다. **새 정보를 최소화하고 회수에 집중**한다.
5. 최신 정보 확인은 편별로 나눠 하지 않는다. **시리즈 전체 범위를 먼저** 확인해야 반전 배분이 가능하다. 단, 확인 범위는 사용자가 준 방향 안으로 한정한다.
