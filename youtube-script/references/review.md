# review.md — 납품 전 검수

집필 직후 실행한다. **명령 4개는 항상 돌린다.** 걸린 항목은 고친 뒤에 보고한다.

아래 명령에서 `$F`는 대본 파일 경로.

```bash
F="scripts/반도체-보조금-전쟁/01-공장은-세워졌다.md"     # 모드 A
F="scripts/반도체-보조금-전쟁/01-공장은-세워졌다.txt"     # 모드 B
```

§1~§4 명령은 모드 A 기준이다 — 낭독 본문만 대상으로 하려고 헤딩·메타 라인·`## 출처` 이후를 제외한다.
**모드 B(순수 대사)는 §7의 전용 명령을 대신 쓴다.** 파일 전체가 낭독 본문이므로 제외 필터가 필요 없고, 대신 마크다운 누출과 사이드카 정합을 확인해야 한다.

## 1. 분량 (필수)

```bash
perl -CSD -Mutf8 -ne 'last if /^## 출처/; next if /^#/ || /^\s*$/ || /^-\s/ || /^---/;
  chomp; s/\s+$//; $n+=length; END{printf "chars=%d  min_310=%.1f  min_370=%.1f\n", $n, $n/310, $n/370}' "$F"
```

`min_310`은 롱폼 내레이션, `min_370`은 토킹헤드 기준 예상 길이.
목표의 ±10%(`formats.md` §1)를 벗어나면 고친다 — 미달은 층을 더 파고, 초과는 중복 재설명을 자른다.

## 2. 긴 문장 (필수)

```bash
perl -CSD -Mutf8 -ne 'last if /^## 출처/; next if /^#/ || /^\s*$/ || /^-\s/ || /^---/;
  for (split /(?<=[.?!])\s+/) { s/^\s+|\s+$//g; printf("%3d | %s\n", length($_), $_) if length($_) > 90 }' "$F"
```

출력이 있으면 **전부 쪼갠다.** 90자 초과 문장은 낭독에서 숨이 끊긴다.

평균 문장 길이도 함께 본다 (롱폼 45~60자, 토킹헤드 30~45자가 목표):

```bash
perl -CSD -Mutf8 -ne 'last if /^## 출처/; next if /^#/ || /^\s*$/ || /^-\s/ || /^---/;
  for (split /(?<=[.?!])\s+/) { s/^\s+|\s+$//g; next unless length; $n++; $t+=length }
  END{printf "sentences=%d  avg=%.1f\n", $n, $t/$n}' "$F"
```

## 3. 금지 표현 (필수)

```bash
grep -nE '알아보겠습니다|살펴보겠습니다|말씀드리겠습니다|다양한|여러 가지|여러가지|많은 사람들|정말 중요|매우 놀라|라고 할 수 있|아시다시피|결론적으로|먼저 .*그다음|구독과 좋아요' "$F"
```

연출 지시가 본문에 새지 않았는지도 확인한다:

```bash
grep -nE '\[(B롤|비롤|자료|화면|인서트|pause|정지|강조|효과음)|※|▶' "$F" | grep -v '^\s*[0-9]*:## '
```

## 4. 사실·출처 정합 (필수)

```bash
# 본문에 등장하는 숫자 목록 — 전부 ## 출처에 대응되는지 눈으로 확인
perl -CSD -Mutf8 -ne 'last if /^## 출처/; next if /^#/ || /^-\s/; while (/([0-9][0-9,.]*\s*(?:년|월|일|%|퍼센트|억|만|천|조|달러|원|배|개|명|건|시간|개월))/g) { print "$1\n" }' "$F" | sort -u
```

- 목록의 모든 항목이 `## 출처`의 소스에 있는지 확인한다. 없으면 **대본에서 빼고** `## 미확인 사항`에 옮긴다.
- 소스가 화자의 주장인 사실은 대본에서도 "~라고 주장합니다"로 되어 있는지 확인한다.

## 5. 수동 체크리스트

### 오프닝
- [ ] 첫 문장이 20자 내외 단문이고, 고유명사나 숫자가 들어 있다
- [ ] 첫 문장에 결론이 없다
- [ ] 인사·채널 소개·목차 낭독이 없다
- [ ] 프레이밍이 이 편의 질문을 한 문장으로 말한다 (결론 방향만 흘리고 내용은 감춤)

### 루프
- [ ] 비트 시트에서 연 루프가 전부 닫혔다 (다음 편으로 넘기는 갈고리는 명시적으로 선언됨)
- [ ] 90~120초마다 루프가 열리거나 닫히는 사건이 있다
- [ ] 동시에 열려 있는 루프가 3개를 넘지 않는다

### 깊이
- [ ] 층 4단계(표면 → 메커니즘 → 원인 → 파급)까지 내려갔다
- [ ] 반전 층이 최소 1개 있고 근거가 함께 있다
- [ ] 구체성 '장면' 단계(사람·시간·행동이 있는 서술)가 3회 이상
- [ ] "N가지 이유" 식 나열로 대체된 구간이 없다
- [ ] 같은 구조의 문단이 3개 연속되는 구간이 없다

### 리텐션
- [ ] 30초 분량마다 새 정보(사실·수치·이름·장면)가 최소 1개
- [ ] 챕터 전환이 "다음으로"가 아니라 새 질문으로 이뤄진다
- [ ] 설명이 2분 넘게 이어지는 구간에 사례나 반론이 끼어 있다
- [ ] 반전 뒤에 호흡 구간이 있다

### 신뢰
- [ ] 시청자가 반박할 지점을 대본이 먼저 말하고 답한다
- [ ] 감정을 형용사로 지시하지 않는다 (사실 배치로 만든다)
- [ ] 추측을 사실처럼 쓴 문장이 없다

### 엔딩
- [ ] 요약 나열이 아니다
- [ ] 프레이밍 질문으로 돌아가 한 문장으로 답한다
- [ ] 마지막 2~3문장이 한 단계 확대된다
- [ ] (시리즈) 갈고리가 예고가 아니라 질문이다
- [ ] 구독 요청이 있다면 클로징 문장 뒤에 한 문장으로만

### 시리즈 정합 (2편 이후)
- [ ] 콜드 오픈 뒤 전편 회수가 1~2문장이고, 전편을 안 본 사람도 이해된다
- [ ] 회수가 요약이 아니라 긴장 복원이다
- [ ] 전편 갈고리를 실제로 받았다
- [ ] 시그니처(오프닝·클로징 문구, 반복 장치)가 유지된다
- [ ] 이 편의 반전이 바이블의 반전 배분과 일치한다 (카드를 앞당겨 쓰지 않았다)

## 6. 모드 B 전용 검사 (순수 대사)

모드 B에서는 §1~§4 대신 아래를 쓴다. §5 수동 체크리스트는 모드와 무관하게 그대로 적용한다.

### 분량

```bash
perl -CSD -Mutf8 -ne 'chomp; s/\s+$//; $n+=length;
  END{printf "chars=%d  min_310=%.1f  min_370=%.1f\n", $n, $n/310, $n/370}' "$F"
```

### 긴 문장 / 평균 길이

```bash
perl -CSD -Mutf8 -ne 'for (split /(?<=[.?!])\s+/) { s/^\s+|\s+$//g; printf("%3d | %s\n", length($_), $_) if length($_) > 90 }' "$F"
```

### 낭독하지 않는 글자 누출 (0건이어야 한다)

```bash
grep -nE '^#|^[[:space:]]*[-*+] |^[[:space:]]*[0-9]+\. |\*\*|`|^---|\[|\]|\(|\)|※|▶|[0-9]{2}:[0-9]{2}' "$F"
```

헤딩·불릿·번호목록·강조·백틱·구분선·대괄호·괄호 주석·타임코드를 잡는다. **출력이 있으면 전부 제거한다** — 괄호는 낭독되지 않으므로 순수 대사에 있을 이유가 없다.

### 사이드카 정합

```bash
[ -f "${F%.txt}.meta.md" ] && echo "meta ok" || echo "MISSING: ${F%.txt}.meta.md"
```

사이드카의 비트 대응 표를 채울 문단 번호는 추정하지 않고 실제 파일에서 뽑는다:

```bash
perl -CSD -Mutf8 -00 -ne 'chomp; $i++; printf("%3d | %s\n", $i, substr($_,0,24))' "$F"
```

- 사이드카가 없으면 납품 불가.
- 사이드카의 `실제 글자수`와 비트 대응 표의 문단 번호가 위 두 명령 결과와 일치하는지 확인한다.
- 대본에 등장한 수치·인용·날짜가 사이드카 `## 출처`에 전부 있는지 확인한다 (§4의 숫자 추출 명령을 필터 없이 돌려 쓴다).

### 문단 구조

```bash
perl -CSD -Mutf8 -00 -ne '$i++; my @s = split /(?<=[.?!])\s+/; printf("%3d | %d sent\n", $i, scalar @s)' "$F"
```

문단당 3~5문장이 목표. 1문장 문단이 연속되면 호흡이 끊기고, 7문장 넘는 문단은 낭독 중 위치를 잃는다.

## 7. 낭독 테스트

체크리스트를 통과했어도 마지막으로 **소리 내 읽는다고 가정하고** 전문을 다시 읽는다.
혀가 걸리는 문장, 숨이 막히는 문장, 동음이의어로 헷갈릴 문장("전자"가 電子인지 前者인지)을 고친다.
숫자는 읽는 방식이 확정돼 있어야 한다 — "520억 달러"를 어떻게 읽을지 애매하면 대본에 읽을 대로 적는다.
