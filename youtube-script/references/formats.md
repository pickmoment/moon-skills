# formats.md — 트랙, 분량, 골격

## 0. 트랙 선택

| 주제 성격 | 트랙 | 이유 |
|---|---|---|
| 사건, 역사, 산업 구조, 인물, 사고 분석, "왜 이렇게 됐나" | **A. 롱폼 내레이션** | 서사와 시간 구조가 있어야 층을 팔 수 있다 |
| 방법론, 경험담, 의견·비평, 도구 사용법, "어떻게 하나" | **B. 토킹헤드** | 화자의 판단과 신뢰가 콘텐츠의 일부 |

애매하면 **관통 질문이 "왜"로 시작하면 A, "어떻게"로 시작하면 B**를 고른다.
한 시리즈 안에서 트랙을 섞지 않는다 — 톤이 깨진다. 특정 편만 성격이 다르면 그 편을 시리즈 밖으로 뺀다.

## 1. 분량 환산 (한국어, 공백 포함 글자수)

한국어 낭독 속도 기준. 실제 녹음 속도가 다르면 사용자 실측값으로 대체한다.

**A. 롱폼 내레이션 — 310자/분** (또박또박, 자료화면과 호흡 공유)

| 길이 | 목표 글자수 | 허용 범위(±10%) |
|---|---|---|
| 10분 | 3,100 | 2,790 ~ 3,410 |
| 15분 | 4,650 | 4,185 ~ 5,115 |
| 18분 | 5,600 | 5,040 ~ 6,160 |
| 20분 | 6,200 | 5,580 ~ 6,820 |
| 25분 | 7,750 | 6,975 ~ 8,525 |

**B. 토킹헤드 — 370자/분** (구어체, 발화 속도 빠름)

| 길이 | 목표 글자수 | 허용 범위(±10%) |
|---|---|---|
| 8분 | 3,000 | 2,700 ~ 3,300 |
| 10분 | 3,700 | 3,330 ~ 4,070 |
| 12분 | 4,400 | 3,960 ~ 4,840 |
| 15분 | 5,550 | 4,995 ~ 6,105 |

- 글자수는 **낭독 본문만** 센다. 헤딩·출처·미확인 사항은 제외 (`review.md` §1 명령이 처리).
- 미달이면 **층을 더 파거나 장면을 추가**한다. 같은 말을 늘려 쓰는 건 금지.
- 초과면 설명을 자르지 말고 **중복 재설명**을 자른다. 그래도 넘치면 편을 쪼갠다.

## 2. 골격

### 트랙 A — 롱폼 내레이션 (18분 / 5,600자 기준)

| 비트 | 타임 | 글자수 | 내용 |
|---|---|---|---|
| 콜드 오픈 | 0:00~0:40 | ~210 | 장면 투척·모순·판돈 중 하나. 루프 A 열기 |
| 프레이밍 | 0:40~1:10 | ~160 | 이 편이 답할 질문 한 문장 + 결론 방향만 흘리기 |
| 1막 배경 | 1:10~5:00 | ~1,200 | 사건 이전의 조건. **설명이 아니라 장면으로.** 작은 반전 1개 |
| 2막 전개·메커니즘 | 5:00~12:00 | ~2,200 | 층 2~3(경로와 원인). 루프 열고 닫기 2회 이상 |
| 전환점 | 12:00~13:30 | ~450 | **반전 층.** 앞의 이해를 뒤집는다 |
| 3막 파급·현재 | 13:30~17:00 | ~1,100 | 층 4. 지금 무엇이 달라졌나. 루프 A 닫기 |
| 클로징 | 17:00~18:00 | ~280 | 프레이밍 질문에 답 + 한 단계 확대 + (시리즈면) 갈고리 |

- 1막에서 배경을 설명하려는 유혹이 가장 크다. **배경은 인물이 등장하는 장면으로 전달**한다.
- 2막이 가장 길다 = 가장 지루해지기 쉽다. 2분마다 루프·사례·관점 전환 중 하나를 배치한다.
- 전환점이 없는 편은 A트랙으로 쓸 만한 주제가 아니다. 재설계한다.

### 트랙 B — 토킹헤드 (12분 / 4,400자 기준)

| 비트 | 타임 | 글자수 | 내용 |
|---|---|---|---|
| 훅 | 0:00~0:20 | ~120 | 결과·수치·반직관 주장. 인사 없음 |
| 자격 한 문장 | 0:20~0:40 | ~120 | 자기소개가 아니라 **왜 내가 이걸 말하나** ("3년간 이걸로 47개 만들었습니다") |
| 프레이밍 | 0:40~1:10 | ~180 | 이 영상이 해결할 문제 + 다 보면 뭘 할 수 있나 |
| 본론 블록 1 | 1:10~4:00 | ~1,050 | 주장 → 근거 → 사례 → 한 줄 정리 |
| 본론 블록 2 | 4:00~7:00 | ~1,100 | 같은 구조. 블록마다 난도를 올린다 |
| 본론 블록 3 | 7:00~9:30 | ~900 | 같은 구조 |
| 반론 처리 | 9:30~11:00 | ~550 | **예상 반박을 먼저 말하고 답한다.** 신뢰가 여기서 생긴다 |
| 클로징 | 11:00~12:00 | ~350 | 가장 먼저 할 한 가지 + 확대 + (시리즈면) 갈고리 |

- 블록은 3~4개. 5개 넘으면 목록이 되고 깊이가 사라진다.
- **블록마다 사례가 있어야 한다.** 주장+근거만 있는 블록은 강의 노트지 대본이 아니다.
- 반론 처리 블록을 빼지 않는다. 토킹헤드에서 이 블록이 신뢰의 대부분을 만든다.

## 3. 트랙별 문체

| | A. 롱폼 내레이션 | B. 토킹헤드 |
|---|---|---|
| 인칭 | 3인칭 관찰자. "나"를 거의 쓰지 않는다 | 1인칭. "제가", "저는" |
| 청자 호칭 | 쓰지 않거나 최소 | "여러분", 2인칭 질문 적극 사용 |
| 종결어미 | "~했습니다", "~입니다" + 현재형 혼용("그리고 그는 거절합니다") | "~거든요", "~잖아요", "~인데요", "~해보세요" |
| 문장 길이 | 중간 길이 + 단문 대비. 평균 45~60자 | 짧다. 평균 30~45자 |
| 감정 | 억제. 사실 배치로 감정을 만든다 | 표현 허용. 단, 형용사 대신 사례로 |
| 군말 | 없음 | 최소한 허용("솔직히", "사실") — 남용 금지 |
| 시제 | 과거 서술 + 극적 현재형 전환 | 현재형 중심 |

**현재형 전환**은 A트랙의 강력한 장치다. 긴장이 최고조인 대목에서 과거형을 현재형으로 바꾸면 장면이 눈앞에서 벌어진다.

> "위원회는 서류를 반송했습니다. 다음 날 아침, 그가 위원장실 문을 두드립니다."

편당 2~3회만 쓴다. 남용하면 효과가 사라진다.

## 4. 시청자 지식 수준

기본은 **관심은 있지만 이 주제는 처음인 사람**. 이 기준으로:

- 전문 용어는 처음 등장할 때 한 문장으로 풀되, 정의문("~란 ~를 말합니다")보다 **기능 설명**("이게 하는 일은 ~입니다")으로.
- 풀어 쓴 용어는 그다음부터 그대로 쓴다. 매번 다시 설명하면 분량만 먹는다.
- 배경 지식이 필요한 대목에서 **설명을 앞에 몰아넣지 않는다.** 필요한 순간에 필요한 만큼만 준다 (just-in-time).
- 시리즈 2편 이후도 각 편이 자립해야 한다. 전편 지식은 콜드 오픈의 회수 1~2문장으로 해결한다.
