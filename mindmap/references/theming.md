# Theming — 테마 4종

팔레트·글꼴은 `visualthink` 스킬과 같다. 같은 문서에 마인드맵과 스케치노트를 함께
넣어도 톤이 어긋나지 않는다. **테마는 스펙을 바꾸지 않는다** — `theme` 만 바꾼다.

| 테마 | 생김새 | 루트 / 갈래 / 잎 | 어울리는 자리 |
|---|---|---|---|
| `sketch` | 따뜻한 종이 위 손그림. 선이 떨리고 붓끝처럼 가늘어진다 | 얼룩진 타원 / 둥근 상자 / 밑줄 | 학습, 아이디어 정리, 설명. "생각 중인 것"으로 읽힌다 |
| `flat` | 깔끔한 벡터. 정확한 기하 | 알약 / 둥근 상자 / 밑줄 | 보고서, 문서에 박아 넣는 그림 |
| `editorial` | 명조 활자 중심. 상자가 없고 괘선이 대신한다 | 이중 괘선 / 괘선 / 점 + 활자 | 긴 글의 구조 요약, 에세이, 공식 문서 |
| `bold` | 포스터. 두꺼운 사각 블록, 하드 섀도 | 검정 슬래브 / 색 슬래브 / 굵은 밑줄 | 발표, 멀리서 읽히는 크기 대비 |

## 고를 때

| 용도 | 추천 |
|---|---|
| 학습·아이디어 정리 | `sketch` |
| 보고서·공식 문서 | `flat` 또는 `editorial` |
| 발표·강연 | `bold` 또는 `sketch` |
| 긴 글 요약 | `editorial` |

`editorial` 과 `bold` 는 **타이포가 주인공이라 라벨이 짧을수록 좋다.** 답답해 보이면
캔버스를 넓히지 말고 단어를 줄인다.

## 분위기 레이어 (`backdrop`)

바탕에 색을 깔아 톤을 잡는다. **정보가 아니라 공기다** — 글자를 방해하기 시작하면
이미 과한 것이다. 기본값은 `none`.

| `backdrop` | 생김새 | 어울리는 자리 |
|---|---|---|
| `none` | 테마 배경색만 | 기본. 문서에 박아 넣을 때 |
| `gradient` | 모서리에서 번지는 옅은 두 색 | 표지·공유용 한 장 |
| `blob` | 크게 번진 색 얼룩 두 개 | 발표 화면, 감정이 실리는 맵 |
| `vignette` | 가장자리만 살짝 어두워진다 | 사진·썸네일이 섞인 맵 |
| `glow` | 중심 노드 뒤의 후광 | 중심이 주인공인 맵 |

`paper`(격자·점·괘선)와 함께 쓸 수 있지만 **둘 중 하나만 고르는 편이 거의 항상 낫다.**

## 범례 (`legend`)

색을 의미로 썼을 때만 붙인다. 왼쪽 아래에 한 줄로 그려진다.

```jsonc
"legend": [
  { "color": "green", "label": "완료", "icon": "check" },
  { "color": "coral", "label": "위험", "icon": "warn" }
]
```

색을 자동 배정에 맡겼다면 범례는 거짓말이 된다 — **색에 뜻을 준 맵에만.**

## 그래픽 요소의 절제

아이콘 · 상태 · 진행률 · 태그 · 썸네일은 **읽는 사람이 훑는 속도를 올릴 때만** 쓴다.

- **아이콘은 갈래(depth 1)에 먼저.** 잎마다 아이콘을 달면 아이콘이 배경이 된다.
- **상태(`status`)는 상태가 있는 맵에만.** 개념 정리 맵에 체크 표시를 달 이유는 없다.
- **진행률은 숫자가 의미 있을 때만.** "왠지 60%" 같은 값은 그리지 않는 편이 낫다.
- **강조(`mark`·`emphasis`)는 한 장에 한둘.** `validate()` 가 셋을 넘으면 경고한다.
- 썸네일은 **말로 설명하기 어려운 것**(화면·사진·차트 캡처)에만.

## 알아둘 것

- **손그림은 `sketch` 에서만 나온다.** 나머지 세 테마는 `roughness: 0` 이라 같은
  그리기 코드가 정확한 기하를 낸다. `seed` 는 `sketch` 에서만 의미가 있다.
- **`mark` 는 테마에 따라 다르게 나온다.** 밝은 바탕 노드에는 형광펜 띠, 색으로
  꽉 찬 노드에는 바깥 링. 흰 글씨 위에 노란 띠를 덮어 글자를 지우는 일은 없다.
- **`paper`** (`grid`/`dot`/`ruled`)는 `sketch` 와 어울리고, `flat`·`bold` 에서는
  대개 방해가 된다. 기본값은 꺼짐이다.
- 인터랙티브 출력에서는 보는 사람이 툴바에서 테마를 바꿀 수 있다. 그래도
  **첫 화면의 테마는 만드는 쪽이 정한다.**
